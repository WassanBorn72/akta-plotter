AKTA Plotterのアプリアイコンを変更しました。

- 紺色の背景にシアンのクロマトグラムと黄色のピークマーカーを配置した専用アイコンを採用
- Macの.appとWindowsの.exeに専用アイコンを設定
- アプリ画面にも同じアイコンを設定（Linuxを含む）

このページの「Assets」から、お使いのPC用のファイルをダウンロードして展開してください。

| PC | ファイル |
| --- | --- |
| MシリーズMac | AKTA-Plotter-macos-apple-silicon.zip |
| Intel Mac | AKTA-Plotter-macos-intel.zip |
| Windows 64ビット | AKTA-Plotter-windows-x64.zip |
| Linux x86_64 | AKTA-Plotter-linux-x64.tar.gz |

操作方法は[README](https://github.com/WassanBorn72/akta-plotter#readme)を参照してください。配布版は引き続き未署名です。SHA256SUMS.txtを整合性確認に利用できます。
