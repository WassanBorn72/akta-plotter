AKTA Plotterの初回正式リリースです。AKTA / UNICORNから書き出したCSVを、PC上で表示・調整・画像保存できます。

## ダウンロード

このページの「Assets」から、お使いのPCに合ったファイルを選んでください。Pythonの別途インストールは不要です。

| PC | ファイル |
| --- | --- |
| MシリーズMac | AKTA-Plotter-macos-apple-silicon.zip |
| Intel Mac | AKTA-Plotter-macos-intel.zip |
| Windows 64ビット | AKTA-Plotter-windows-x64.zip |
| Linux x86_64 | AKTA-Plotter-linux-x64.tar.gz |

Macでは展開したAKTA-Plotter.appを起動します。Windows・LinuxではAKTA-Plotterフォルダ全体を保持し、内部の実行ファイルを起動してください。LinuxはUbuntu 22.04以降などのGUI環境（glibc 2.35以上）を対象とします。

## 機能

- CSV / TSVの読み込みと、Injectionより左の数値項目の選択
- 各信号のmL列を横軸として描画し、単位ごとのY軸を表示
- 複数ファイル・複数曲線の重ね合わせ
- 軸の範囲、主目盛り・副目盛りの間隔、数値表示の調整
- 曲線ごとの色・線の太さの変更
- PNG / SVG / PDF出力と解像度の指定

データはローカルで処理します。通常の利用にインターネット接続は不要です。

## ご利用にあたって

アプリは開発者署名・Apple公証を行っていません。OSの初回起動警告が表示された場合は、入手元を確認し、OSの許可画面を使用してください。

単位換算、曲線の位置合わせ、フラクション表示、ピーク積分、分子量校正は未対応です。異なるエクスポート形式では読み込めない場合があります。

操作方法は[README](https://github.com/WassanBorn72/akta-plotter#readme)、不具合の報告は[Issues](https://github.com/WassanBorn72/akta-plotter/issues)を参照してください。SHA256SUMS.txtは各配布ファイルの整合性確認用です。
